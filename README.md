# DX11 Physics Framework

A C++ physics and graphics project developed using DirectX 11.

## Overview

This project explores the implementation of basic real-time physics and graphics systems using C++ and DirectX 11.

The project includes work with:

* Gravity
* Drag
* Friction
* Collision detection
* Basic particle systems
* DirectX 11 rendering

The project was developed to gain practical experience with physics programming, graphics programming and the systems involved in a real-time simulation.

## Controls

* **Number keys (1–9)** — Control the corresponding cubes
* **Note:** Use the number keys above the letters, not the numeric keypad.

## Technologies

* **C++**
* **DirectX 11**
* **Visual Studio**

## Physics

The project explores fundamental physics concepts including gravity, drag and friction.

Collision detection is also used to handle interactions between objects within the simulation.

## Graphics

The project uses DirectX 11 for real-time rendering and includes a basic particle system as part of the graphics work.
